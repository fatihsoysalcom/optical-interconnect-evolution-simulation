# Optical Interconnect Evolution Simulation

This Python script simulates the evolution of optical interconnect technologies, demonstrating the progression from MPO to NPO and finally to CPO. It highlights key improvements in data rate, latency, and power consumption for each stage.

## Language

`python`

## How to Run

Run the script using a Python interpreter: `python optical_evolution.py`

## Original Article

This example accompanies the Turkish article: [1.6T ve Ötesi: MPO, NPO ve CPO Arasındaki Temel Değişimi Anlamak](https://fatihsoysal.com/blog/1-6t-ve-otesi-mpo-npo-ve-cpo-arasindaki-temel-degisimi-anlamak/).
